# Voice evaluation plan

A voice agent can compile and still be unusable.

## Clinic benchmark
At least 200 synthetic/consented calls across Bangla, English, Banglish, quiet/noisy audio, fast/slow speakers, interruptions, weak codecs/network.

## Intent groups
Hours, location, services/prices, availability, booking, reschedule/cancel, ambiguous dates, names/numbers, changed intent, human request, unsupported medical question, complaint, knowledge miss, tool timeout, transfer failure.

## Score
Task success, factual accuracy, tool correctness, handoff correctness, language quality, interruption recovery, verbosity, first-audio latency, duration, provider cost.

No provider/prompt becomes default from a few good demos. Compare against the fixed benchmark and pilot data.
