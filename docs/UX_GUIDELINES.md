# UX guidelines

## Onboarding target
A simple business should reach a test call in under 30-60 minutes:
workspace → template → business knowledge → language/voice → number/SIP → transfer → integration → test → publish.

## Agent builder
Use structured sections: Identity, Voice/language, Knowledge, Actions, Handoff, Hours, Safety, Testing. Advanced prompt editing is secondary.

## Call detail
Show metadata, transcript, summary, intent/outcome, tool activity, transfer, latency/QA, cost, and prompt/agent version.

## Trust
Clearly distinguish draft/live, test/production, connected/disconnected, estimated/actual cost, demo/real data.

Every screen needs useful empty/error/loading states once connected to real data.
