# Design system

Professional B2B SaaS: calm, precise, trustworthy, modern.

## Components
Buttons, inputs, cards, status badges, tables, dialogs/drawers, toasts, skeletons, empty states, confirmations.

## Rules
- Color is not the only status signal.
- Visible keyboard focus.
- Forms need labels and validation.
- Destructive actions require confirmation.
- Tables need mobile behavior.
- Dashboard favors useful density over marketing-scale typography.
- Mobile and desktop are both first-class.
