# First sellable demo — clinic/dental receptionist

## Demo story
Caller phones a fictional clinic. AI greets naturally, answers approved FAQs, handles Bangla/Banglish/English, checks availability, confirms slot, books it, and can transfer to a receptionist.

## Required intents
Location, hours, services, approved prices, practitioner availability, booking, reschedule/cancel, human request, unsupported medical advice → safe refusal/handoff.

## Acceptance
No invented facts. Booking comes from real tool result. Interruption works. Dates/times confirmed. Human request transfers or captures a message. Call appears with transcript/outcome/tools/duration/cost. Test all three language modes.

## Sales demo
Show live call → calendar booking → dashboard record → owner edits FAQ/transfer → cost/outcome analytics.
