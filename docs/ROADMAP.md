# Roadmap

## Now — sellable clinic demo
Supabase auth/workspace, real agent CRUD, clinic knowledge, LiveKit/SIP test route, Google Calendar booking, human transfer, call detail storage, usage/cost, voice evals.

## Next — paid design partners
3-5 customers, prompt versions, QA evaluator, generic REST/n8n, e-commerce lookup, internal admin, basic billing enforcement.

## Then — self-serve/reliability
Member invites/RBAC, provider failover, onboarding templates, knowledge sync, retention controls, observability, partner/reseller features.

## Later
Compliant outbound workflows, more integrations, enterprise controls, regional routing, deeper analytics, selective self-hosting.

Customer evidence can change order. Reliability and paid use outrank breadth.
